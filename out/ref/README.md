## 数字

- 图上印刷的比例尺条：0 -> 5 m = 70.86 pt，即 **1 pt = 70.5617 mm（1:200）**
- 单位 05 尺寸链：北 250/2100/320/2200/250 = 5120；南 100/2040/390/3655/250 = 6435；
  东 200/730/1135/1560/2990/250 = 6865
- 室内净面积 **37.16 m²**；在官方图上量得 37.6 m²（差 1.2%）
- 商品页 493 平方呎 = 45.8 m² 实用面积，45.8 x 0.81 = 37.1 —— 差额正好是内墙 + 外墙一半
