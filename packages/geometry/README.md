# hkgeometry —— 整屋 3D 空间优化的几何内核

> 技术方案 v3.2 §2 / §8 的参考实现。
> **它是 v3.2 §17 里唯一被四处共用的包**：求解器用它做目标函数、
> 校验器用它做视线检查、渲染器用它画热力图、训练数据生成器用它造标签。

## 这块代码解决什么

把「**视觉显大**」这个美学词，变成**可以精确计算、可以被求解器优化**的数字。

核心公式（§2.4）：

    exposure(cell) = normalize( Σ_v  w_v · visible_v(cell) · prominence(v, cell) )
    prominence(v, cell) = 1 / (1 + d(v, cell) / D0)

    ★ 把视觉体量大的家具，放到曝光度最低的位置。

    visual_mass(item) = 面积(m²) × 高(m) × 实心度 × (1 - 明度)

## Demo 结果（实测）

同一套 5 件家具、同一个 L 形客廳（3200×2800，层高 2450，顶部有梁）：

| 方案 | 显大分 | 关键差别 |
|---|---|---|
| 舊擺法 | **52** | 2.2m 深色衣柜正對大門；1.2m 電視櫃擋在進門→窗的斜線上 |
| 新擺法 | **83** | 同一套家具，體量挪到 L 形凹位造成的低曝光區，主視線讓開 |
| 新擺法 + 換矮櫃 | **89** | 再把 1.2m 電視櫃換成 0.45m 通透矮款 |

**家具一件没少，只是换了位置和款式。**

## ★ 三个必须知道的技术要点

### 1. 曝光度在「凸的矩形空房间」里会退化成纯距离

矩形空房间里任何一点都看得见任何一点，`visible` 恒为 1，
曝光度只剩 `prominence`（离门口越近越显眼）。
**曝光度真正发挥作用要靠：**
- **非凸户型**（L 形 / 凹位 / 入門玄關）—— 香港极常见
- **家具互相遮挡** —— 真正的常态

所以演示户型用了 L 形。如果你的房间是规规矩矩的矩形，这一个指标会失效，
必须靠 `corridor` + `occlusion` 补上。

### 2. 参数是校准出来的，不是拍脑袋定的

`_calibrate.py` 是一个扫描脚本，用来给 `exposure_map` 的
`entrance_weight` 和 `d0_mm` 找合适的值。当前值：

    entrance_weight = 6.0     # 进门第一眼最重要
    d0_mm          = 800.0    # 距离衰减尺度

**校准依据**：让「衣柜放门口 vs 放低曝光区」这个差别在
`visual_mass_exposure` 上产生最大分离（实测 0.63 → 0.41）。

> ⚠️ 这些值是**几何上自洽但未经过人类感知验证**的。
> 它们对不对得上人的感觉，要靠方案 §2.7 的 VLM 成对比较来校准。
> **这正是里程碑 M1 排在 M3（训 Transformer）之前的原因** —— 先校准靶子，再造子弹。

### 2b. ★ 视觉体量必须压缩，不能直接四因子连乘

原始公式 `面积 × 高 × 实心度 × (1-明度)` 是**四个因子连乘**，实测同一批
SKU 里 最大/最小 = **79 倍**（深色到顶柜 vs 浅色开放层架）。

而 `layout_mass_exposure` 是**体量加权平均** —— 79 倍的权重差会让优化器
实际上只在乎那一件柜子，剩下 90% 的家具被忽略。感知上也差不到 79 倍。

所以取 **0.45 次方**压缩到 7.2 倍（`types.py: VISUAL_MASS_EXPONENT`）：

| 指数 | max/min | 五件家具权重分布 |
|---|---|---|
| 1.00（原始） | 79× | 0.50 / 0.24 / 0.23 / 0.02 / **0.006** |
| **0.45（采用）** | **7.2×** | 0.36 / 0.25 / 0.25 / 0.09 / **0.05** |

> 这是 `data/catalog` 那份 150 SKU 数据集的制作者独立发现的同一个问题
> （101/150 条 vmi < 0.1，严重右偏），并建议展示层改用 percentile rank。

### 3. 显大分是「地板分 + 跨度分」

    score = 25 + 75 × Σ(权重 × 各项得分)

各项得分都是**带自由額度的归一分**，例如体量曝光度：

    t_mass = 1 - max(0, mass_exposure - 0.35) / (0.40)

意思是「曝光度 0.35 以下不扣分，0.75 扣光」。这样比直接用
`1 - value` 更能拉开差距，也更符合直觉（一个稍微显眼的柜子不该被重罚）。
